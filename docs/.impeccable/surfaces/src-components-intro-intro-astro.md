## Direction contract

THESIS: The site is an 1980s comic magazine printing an anime. The splash is the cel — ink line, flat cel colour, acetate; the docs are the printed page — 45% halftone, panel gutters, caption boxes. It refuses the category default: a dark hero canvas bolted onto a stock docs theme, and its opposite, a full-screen game with no readable documentation.

OWN-WORLD: Indigo-night `#12142a` void, ink `#0b0c16`, paper `#f2ecdf`, cel vermillion `#ff5a36`, cyan `#39c7d6`, magenta `#ff4f9a`, cream `#ffe9b0`, acid green `#8fd14f`; UI signal is vermillion. Anton display, Inter body, JetBrains Mono notation. Every body carries an ink outline; halftone only on shadows, margins, transitions — never under body text. Caption boxes, panel gutters, ticked numbered index, revision block.

STORY: A three.js developer sees thousands of instances living at 60fps, believes the library is real, and reads the docs without leaving the world.

FIRST VIEWPORT: Full-bleed cel space: ship low-centre in chase frame, belt and planets around it, eyecatch bar (56px) across the top, caption-box console in the corners, a small tab of the legend plate after the first input. Primary action: fly to a planet; the doc page unlocks as a comic panel.

FORM: Pinned direction "Cel & Retino" (user pin, no seed key), drawn from the cel-animation, halftone-print and model-kit-manual candidates.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
